农历工具，可直接传入日期获取农历信息。运用复杂的地月日计算，得出农历。

## 1. 速查表

| 属性  | 描述     |
| ----- | -------- |
| numCn | 中文数字 |
| Gan   | 天干     |
| Zhi   | 地支     |
| ShX   | 生肖     |
| Jq    | 节气     |
| Ym    | 月名     |
| Rm    | 日名     |
| Yxm   | 月相名   |
| JNB   | 假日表   |



## 2. 获取农历节日

当前方法返回的为一个对象，包含了super、common、other三个字段

其中 super 为重要节日，如：“春节”
common 为普通节日，如：“重阳节”
other 为其他节日



通过公历日期获取：getFestival

### 参数：

| 序号 | 名称  | 类型 | 含义   |
| ---- | ----- | ---- | ------ |
| 1    | year  | 数字 | 公历年 |
| 2    | month | 数字 | 公历月 |
| 3    | day   | 数字 | 公历天 |



通过日全信息获取：getFestivalByDayAllInfo



## 3. 获取生肖 - getChineseZodiac

传入农历年获取生肖



## 4. 获取干支

传入农历年获取信息

获取天干：getGan

获取地址：getZhi

获取干支：getCyclical



## 5. 获取黄帝纪年 - getHuangdiYear

传入农历年获取黄帝纪年，黄帝纪年，是根据黄帝即位以及创制历法的时间开始纪年



## 6. 获取朝代 - getDynasty

传入公历年获取朝代信息，可追溯到做早可追溯到夏朝



## 7. 获取月的所有农历日 - getMonthDays

传入公历的年和月获取公历当前月的所有农历日信息



## 8. 获取农历月信息 - getMonthInfo

传入农历的年和月，获取农历月信息



## 9. 获取日的所有信息 - getDayAllInfo

### 参数：

| 序号 | 名称  | 类型 | 含义   |
| ---- | ----- | ---- | ------ |
| 1    | year  | 数字 | 公历年 |
| 2    | month | 数字 | 公历月 |
| 3    | day   | 数字 | 公历天 |



## 10. 获取节气 - getSolarTermsInfo

### 参数：

| ---- | ----- | ---- | ------ |
| 1    | year  | 数字 | 公历年 |

## 11. 农历转公历

仅支持1900.1.31~2100.12.1参数

### 参数：

| 序号 | 名称         | 类型 | 含义   |
| ---- | ------------ | ---- | ------ |
| 1    | chineseYear  | 数字 | 农历年 |
| 2    | chineseMonth | 数字 | 农历月 |
| 3    | chineseDay   | 数字 | 农历天 |
