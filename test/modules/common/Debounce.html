Debounce

1. 普通用法（全局防抖）

    bt1.addEventListener('click', () => {
        Baitu.Debounce.of(() => {
            ta1.value = "普通用法";
        }, 3000)
    });

2. 多实例化

    const de1 = Baitu.Debounce.new();
    const de2 = Baitu.Debounce.new();
    bt2.addEventListener('click', () => {
        de1.of(() => {
            ta2.value = "第一个";
        }, 1000)
        de2.of(() => {
            ta2_1.value = "第二个";
        }, 3000)
    });

3. 闭包方法（全局）

    bt3.addEventListener('click', Baitu.Debounce.with(() => {
        ta3.value = "闭包用法";
    }, 3000));

4. 闭包多实例

与普通方法相同用法 
    const de3 = Baitu.Debounce.new();
    const de4 = Baitu.Debounce.new();
    bt2.addEventListener('click', de3.with(() => {
        ta2.value = "第一个";
    }, 1000));
    bt3.addEventListener('click', de4.with(() => {
        ta3.value = "第二个";
    }, 3000));
