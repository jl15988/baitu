Throttle

1. 普通立即执行（全局节流）

    let num = 1;
    bt1.addEventListener('click', () => {
        Baitu.Throttle.of(() => {
            ta1.value = num++;
        }, 3000)
    });

2. 最后执行

    let num2 = 1;
    bt2.addEventListener('click', () => {
        Baitu.Throttle.of(() => {
            ta2.value = num2++;
        }, 3000, false)
    });

3. 闭包方法（全局）

    bt3.addEventListener('click', Baitu.Throttle.with((e) => {
        console.log(e);
        ta3.value = num3++;
    }, 3000));
